# The Dead Man's Switch — AncientCorps 2.0.0

`1.6` 分支凍結（DMS1 世代，不再更新內容），本次所有變更都在新的 `1.7` 分支。
英文摘要見文末。

## 版本與依賴

- 支援版本仍為 1.5 / 1.6 / 1.7，但 **1.6 內容與 DLL 全部凍結**；1.7 是從 1.6 分出的完整內容分支。
- `About.xml` 改用 `modDependenciesByVersion`，1.6 / 1.7 都明列 **Dead Man Switch、Fortified Features Framework、Harmony、Biotech**。
  （本模組的 Def 直接使用 `Fortified.*` 型別，FFF 一直是硬性前置，只是先前沒有宣告。）
- `LoadFolders.xml`：`v1.7` 只載入 `/`、`1.7`（以及 CE / D_Lib / Cinders 條件資料夾），不再沿用 `1.6`。
- 建置目標改為只有 `net10.0` → `1.7/Assemblies`，避免 `dotnet build` 覆蓋 1.6 凍結的 DLL。
  程式碼現在直接參考 `Fortified.dll`（使用 FFF 的 Huntdown 與多砲塔型別）。

## 新內容

### 榖倉（Saray）／РГМ-4「工蜂」
- 新輕型履帶雜務機：低甲、中速、**二帶寬**，與蹄兔共用履帶構造（`DMS_Caterpillar`）。
- 工作類型：搬運、建築、種植；武裝只有一具遙控武器站，可換用手槍／短管衝鋒槍／茲洛賓左輪。
- 技能 **消防泡沫**（`CompAbilityEffect_Firefoampop`）。
- 培育配方 `DMSAC_Make_Saray` 掛在 DMS2 的 I 級封存檔案「駐屯兵器」底下。
- 加入派系編制、巡邏池與未啟動機兵池（低權重，因為它是後勤機）。

### 八音盒（Music Box）小 Boss
- 籬笆底盤重造：肩上兩座**集群火箭發射艙**（六管齊射）＋ 榴彈機槍。
- 專屬 `BossDef` / `BossgroupDef`（三波護衛戰）與 **火力召喚信標**（`DMSAC_BossCaller`，FFF `CompUseEffect_SummonRaid`）。
- 美術暫用 `zabor` 貼圖佔位；新貼圖到位只要換 `bodyGraphicData.texPath`。

## 採用 FFF 1.7 系統

- **設施警報網路**（不動 236 KB 佈局）：指揮核心 = 掃描器 + 封鎖控制器（可駭入解除）、處理陣列與通風扇 = 警報時放出機兵、地表電梯 = 封鎖閘門。
- **機甲殘骸回收**：六族機兵可用 `Recycleable` 拆解回收。
- **兵器墳場**改用 `GenStep_FFFGarrisonedStructure`：殘骸散落、戰利品進儲藏、守軍入駐。
- **DEFCON 五級**啟動 FFF `HuntdownDef`（警告 → 倒數 → 逐波增援），不取代既有巡邏與 DEFCON 動作表。

## 修正（挑重點）

- **設施襲擊閘門**：`SitePartWorkerTick` 每 tick 都被呼叫，而 `lastRaidTick` 在連隊行動路徑上永不重新上膛 → 90k tick 後每個 tick 都在擲占領／生成新連。已改為固定取樣 + 兩條路徑共用冷卻。
- 敵對判定寫反（襲擊只在非敵對時發生）已修正。
- **固定砲塔機兵不再自動撤退**：`equipment.Primary == null` 會讓稜堡／多砲塔城邦在 600 tick 內集體離場。
- **不再改壞遊戲 lister**：`JobGiver_AIDisarmingDistant` 原本對 `ListerThings` 的內部清單做 `RemoveWhere`，會把非遠程武器從全地圖永久除名。
- `IsAssignableFrom` 參數顛倒（自動門、多砲塔等子類永遠選不到）共 3 處。
- DEFCON：`First()` → `FirstOrDefault()`；不再直接寫 `FactionDef.defeated`；0 級現在會自己上升；連隊上限與警戒等級不再反向。
- 連隊：不再把連隊疊在目標聚落或海上；`ShouldRemoveMapNow` 恢復原版所有守衛。
- 巡邏隊：不再誤撿別派系的 `StageThenAttack` lord；不會在讀檔瞬間出巡。
- `LordJob_DefendTargetAndAssaultColony` 補上**無參數建構子**（原本載入存檔一定失敗）。
- Harmony 補丁改為逐類別套用（Harmony 3 一個類別失敗會中止 `PatchAll`）。
- 清除死碼：`CircleConst`、`WorldUtils` 重複方法、自製 `JobDriver_ResurrectMech`、`QuestNode_GetSiteTile`、`PlatoonMaker`、空 `SitePartWorker_Artillery`。
- XML 補丁：`D_Lib_Patch` 原本指向不存在的 `DMSAC_Bullet_StugnaATGM`（改指向 `DMSAC_Grenade_Stugna`）；CE 的迫擊砲／自走砲 charges 補丁補上 `comps` 節點。

## English summary

- `1.6` content and DLL are frozen; everything ships in a new `1.7` branch that no longer loads `1.6`.
- Declared dependencies properly (DMS2, FFF, Harmony, Biotech); the build now targets `net10.0` only and references `Fortified.dll`.
- New: RGM-4 "Saray" tracked utility mech (2 bandwidth, hauler/builder/planter, firefighting foam), the "Music Box" mini-boss (twin cluster rocket nests + grenade MG) with a summon beacon, and six installable mech modules built on FFF's Modification system.
- Balance: per-role weapon loadouts for the four line units, Zabor rebalanced toward melee, Gorod toward ranged.
- FFF 1.7 systems adopted: facility alarm network and lockdown on the existing underground layouts (no layout edits), hulk recycling, garrisoned-structure generation for the graveyard, and a DEFCON-5 Huntdown.
- Fixed a long list of defects, notably the site raid gate that rolled every tick after 90k ticks, fixed-mount mechs deserting raids, lister corruption, reversed `IsAssignableFrom` checks, DEFCON level-0 freeze, and the missing parameterless lord-job constructor that broke save loading.
